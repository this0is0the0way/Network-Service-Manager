# CHANGELOG — Network Service Manager

## v2.5.4 — 2026-09-16

### 2026-09-16 — Улучшение мастера создания профилей

- Во время создания объекта и на каждом шаге создания профиля `exit` или
  `cancel` отменяют мастер без сохранения.
- Маска по Enter теперь принимает стандартное значение `255.255.255.0`; также
  принимаются сокращённые записи `/24` и `24`.
- Мастер предлагает режимы `Network`, `MultiAddress`, `Routes` и `Mixed` и
  запрашивает нужные адреса или маршруты для выбранного режима.
- Описание категории уточнено: это только группа в списке профилей объекта и
  она не меняет настройки адаптера.

### 2026-09-16 — Устойчивость инициализации адаптера

- Анализ драйвера после выбора адаптера повторяется до четырёх раз с паузой
  1,5 секунды, если расширенные свойства временно недоступны.
- При окончательной ошибке программа возвращает к выбору адаптера и не
  продолжает работу с неполностью инициализированным устройством.
- Каждая промежуточная попытка записывается в журнал как
  `Action=AdapterInitialization; Result=Retry`.

## v2.5.2 — 2026-09-15

### 2026-09-15 — Обнаружение адаптеров и исправление применения профиля

Причины: ложное определение поддержки VLAN по скрытому IntelANSVlanID,
использование устаревших возможностей адаптера и ошибка при отсутствии PingTarget.

- Повторная проверка физических адаптеров и текущего драйвера при возврате в меню и перед сетевыми операциями; замена проверяется по InterfaceGuid.
- Сохранённые VLAN-возможности больше не подменяют результаты текущего обнаружения.
- Скрытый IntelANSVlanID без подтверждающего имени поля больше не объявляется поддерживаемым способом прямой настройки VLAN.
- Packet Priority & VLAN исключён из кандидатов VLAN ID; неизвестное непустое значение не сбрасывается автоматически.
- Отсутствующее значение VLAN не требует операции сброса; ошибки чтения драйвера останавливают операцию.
- Возврат DHCP проверяет снятие VLAN перед изменением IPv4.
- Исправлена проверка необязательного PingTarget при его отсутствии в профиле.
- Добавлены автономные проверки tests/AdapterDetection.Tests.ps1 с имитацией драйверов, без изменения сети.

Изменённые файлы:
- NetworkManager.ps1 — обнаружение, проверка адаптера и применение настроек.
- README_RU.md, README_ENG.md — описание повторного обнаружения и ограничений VLAN.
- tests/AdapterDetection.Tests.ps1 — автономные регрессионные проверки.
- CHANGELOG.txt — история изменений и результаты проверки.
- README.md, RELEASE_MANIFEST.txt — версия и состав релизного архива.
- .gitignore — исключения для локальных ZIP-архивов и каталога dist.
- RELEASE_NOTES_v2.5.2.md — описание релиза для GitHub.

Проверка:
- powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\AdapterDetection.Tests.ps1 — PASS в Windows PowerShell 5.1.
- Проверены имитации Intel и ASIX, сброс к значению драйвера по умолчанию,
  обновление возможностей, ошибки чтения, отключение/замена адаптера,
  применение профиля без PingTarget и отказ до изменения IPv4 при неподдерживаемом VLAN.
- Синтаксический разбор PowerShell и git diff --check — без ошибок.

Ограничения:
- Пользователь подтвердил успешное тестирование сборки у коллеги. Точный набор
  аппаратных сценариев не указан; назначение тегированного VLAN на Intel I219-V
  в Windows 11 не считается подтверждённым. Автономные тесты не меняли сеть.
- Повторное обнаружение выполняется при возврате в меню и перед сетевыми операциями;
  фонового опроса во время ожидания ввода нет.
- Наличие скрытого IntelANSVlanID не подтверждает возможность задания VLAN.
- Пользователь подтвердил Windows 11. Intel PROSet/ANS VLAN официально не поддерживается
  в Windows 11: https://www.intel.com/content/www/us/en/support/articles/000087483/ethernet-products.html
- Подготовлен релиз 2.5.2: обновлены версия программы и документация,
  создан чистый ZIP без пользовательских данных и файлов разработки.

## v2.5.1

### BRANDING
- Публичное название проекта и GitHub-репозитория изменено на `Network Service Manager`.
- Имя `BESKAR` намеренно сохранено внутри консольного интерфейса и при запуске PowerShell-скрипта.
- Основной файл запуска остаётся `NetworkManager.ps1`.

### FIX / UX
- Выровнено отображение команд в `help`.
- В мастере `add ip` добавлен безопасный выход без сохранения через `exit` или `cancel` на любом шаге.
- Русская команда отмены не используется.


### FIX
- Исправлена автоматическая проверка `PingTarget`: вместо `Test-Connection -TimeoutSeconds` используется стандартный `ping.exe`.
- Устранена ошибка совместимости с Windows PowerShell 5.1, где параметр `TimeoutSeconds` может отсутствовать.
- Сохранена логика повторных попыток: после первого успешного ответа дальнейшие попытки не выполняются.

### NEW
- Добавлена команда `devicename`.
- Через `devicename` можно включать и отключать отображение `DeviceName` при применении профиля.
- `devicename` добавлена в `help`.
- `pingtarget` остаётся доступной через команду и `help`, но удалена из строки быстрого доступа главного меню.
- `devicename` также не выводится в строке быстрого доступа главного меню.

### PRESERVED
- Автоматическое определение VLAN-драйвера.
- Поддержка `VLAN_ID`, `RegVlanID` и других вариантов.
- Проверка снятия VLAN при переходе на профиль без VLAN.
- Объекты и профили.
- `edit` и `edit N`.
- `ping` и `ping IP`.
- `theme`.
- `add ip`.
- `dhcp`, `state`, `reboot`.
- MultiAddress / Routes / Mixed.
- Скрытие APIPA только в интерфейсе BESKAR.
- Автоматическое изменение размера окна.
